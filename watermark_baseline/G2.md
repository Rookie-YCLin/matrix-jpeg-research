# G2｜第二奇異值嵌入強度與 JPEG 後 BER

本比較依 [Issue #8](https://github.com/Rookie-YCLin/matrix-jpeg-research/issues/8) 與 [Issue #10](https://github.com/Rookie-YCLin/matrix-jpeg-research/issues/10) 的研究方向，疊接 [W0 PR #13](https://github.com/Rookie-YCLin/matrix-jpeg-research/pull/13) 和 [W0-D PR #14](https://github.com/Rookie-YCLin/matrix-jpeg-research/pull/14)。只調整 d2。每個新上游實例保留 d1=36 與 common 路徑，由包裝器設定同一 d2 供嵌入和擷取。分別從三張固定 RGB 原圖嵌入，再從各自的 PNG 獨立編碼 Q10、Q20、Q30，皆為 4:4:4。

## 結果

| d2 | 無攻擊錯誤／96 | PNG PSNR（dB） | Q10 錯誤／96（BER） | Q20 錯誤／96（BER） | Q30 錯誤／96 |
|---:|---:|---:|---:|---:|---:|
| 10 | 0 | 38.55–39.03 | 18（18.75%） | 74（77.08%） | 0 |
| 20 | 0 | 37.59–38.20 | 12（12.50%） | 78（81.25%） | 0 |
| 30 | 0 | 36.23–36.98 | 19（19.79%） | 72（75.00%） | 0 |

| d2 | Q10 JPEG PSNR（dB） | Q20 JPEG PSNR（dB） | Q30 JPEG PSNR（dB） |
|---:|---:|---:|---:|
| 10 | 26.24–28.36 | 28.07–30.41 | 29.22–31.65 |
| 20 | 26.22–28.32 | 28.04–30.36 | 29.16–31.49 |
| 30 | 26.20–28.31 | 27.95–30.06 | 28.98–31.12 |

兩種 PSNR 都以原圖為參照。PNG 欄衡量嵌入失真，JPEG 欄涵蓋嵌入與壓縮的總失真。比較圖的淺藍帶標出每張圖 d2=20 的 PNG PSNR ±1.0 dB，三種 JPEG 品質以一致顏色顯示。Q30 的 BER 柱高皆為零。[逐位結果](../outputs/run-g2/results.csv) · [比較圖](../outputs/run-g2/comparison.png)

| 影像 | 候選 d2 | ΔPNG PSNR（dB） | 相近品質 | Q10 Δ錯誤數 | Q20 Δ錯誤數 | Q30 Δ錯誤數 |
|---|---:|---:|:---:|---:|---:|---:|
| astronaut | 10 | +0.966 | 是 | +2 | −4 | 0 |
| chelsea | 10 | +0.878 | 是 | +2 | 0 | 0 |
| coffee | 10 | +0.830 | 是 | +2 | 0 | 0 |
| astronaut | 30 | −1.360 | 否 | +2 | −5 | 0 |
| chelsea | 30 | −1.342 | 否 | +3 | +2 | 0 |
| coffee | 30 | −1.220 | 否 | +2 | −3 | 0 |

差值一律為候選減 d2=20。逐圖 ΔBER 為 Δ錯誤數除以 32。配對表另保存每張圖、每個品質的 ΔJPEG PSNR 與未四捨五入的門檻判斷。1.0 dB 是本研究事前設定的操作標準。[配對數據](../outputs/run-g2/paired.csv)

**書面摘要。** 在相近的含浮水印影像品質下，d2=10 在主要條件 Q10 的三張影像各多錯 2 位，合計 BER 由 12.50% 升至 18.75%。Q20 下，astronaut 的錯誤由 20/32 降至 16/32，其餘兩張不變。d2=30 在 Q20 的總錯誤減少 6 位，但三張圖的含浮水印 PNG PSNR 都下降超過 1.0 dB。Q30 及無攻擊 PNG 均為零錯誤。這組結果顯示 d2 會改變失真和 BER，其方向取決於影像與攻擊條件。主要條件未觀察到相近品質下的 BER 改善。

## 判決診斷與限制

獨立診斷對每個條件執行原版聚合、K-means 與位元還原，1,152 個群標籤均與公開 bit API 相同。診斷中點為可重現分群標籤的兩群平均中點，另記錄最近群間距。Q20 的九組影像與參數均呈現原始 0 的事後平均分數高於原始 1。Coffee 在 d2=10 和 20 各全反 32 位，d2=30 仍錯 29 位。均值順序反向與逐位全部翻轉是不同欄位。正確位元只在解碼完成後用來標記現象，沒有調整判決或 BER。[判決分數](../outputs/run-g2/decision_scores.csv)

範圍限三張影像、單一 payload、每組 96 位元和固定 JPEG 編碼設定。Q20 的局部改善屬事前指定的失效案例。待審查重點為主要條件的退步、Q20 群方向反轉的解讀，以及報告中對 1.0 dB 門檻的表述。

## 重現與驗收

從專案根目錄依 [W0 環境說明](README.md) 安裝 Python 3.13 鎖定依賴。輸出目錄須為新目錄。

```text
python -m watermark_baseline.g2 --output-dir outputs/run-g2-review
python -m watermark_baseline.g2 --output-dir outputs/run-g2-review-repeat
python -m watermark_baseline.compare_runs outputs/run-g2-review outputs/run-g2-review-repeat
python -m pytest -v
```

同一 Windows 環境下，d2=20 與 W0 的三張 PNG 及 W0-D 的九張 JPEG 的位元、PSNR、SHA-256 均相同。兩次 G2 重跑的 41 個索引檔案逐檔一致。跨平台重跑核對歷史位元和 PSNR，記錄檔案雜湊差異。[manifest](../outputs/run-g2/manifest.json) · [重跑比對](../outputs/g2-replay-comparison.json) · [pytest](../outputs/pytest-g2.txt)
