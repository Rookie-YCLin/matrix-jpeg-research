# 零相位保序候選｜執行前固定規格

本工作依 [G5 前置診斷 PR #21](https://github.com/Rookie-YCLin/matrix-jpeg-research/pull/21) 及主持人授權，只在新候選實例替換上游 common 的區塊奇異值嵌入。步長固定 36、20，相位固定零。DWT、DCT、洗牌、色彩、JPEG、密鑰及公開 bit 擷取維持原版。保留原版 RGB、payload、密鑰及 Pillow 4:4:4、optimize=False、progressive=False。兩方法均重新從原圖嵌入，所有 JPEG 各自從相應 PNG 獨立編碼。

對 bit b，令 a0=9+18b、a1=5+10b。選 q0=a0+36k0、q1=a1+20k1，其中 k0、k1 為非負整數且 q0≥q1≥s2。目標最小化 (q0−s0)²+(q1−s1)²，平手先取較小 q0，再取較小 q1。上取整 q1 至不低於 s1 的格點，再上取整 q0 至不低於 max(s0,q1) 的格點，構成可行解。此時 q1−s1<20、q0−s0<56，故最優解必滿足 |q1−s1|<60。枚舉這個有限窗口，固定 q1 後取最接近 s0 的可行 q0，得到全域最小值。程式以輸入浮點值的精確二進位分數比較平方代價。正交變換保持 Frobenius 範數，因此該平方和等於理想區塊的平方改動。保序與格點餘數證明的是理想 SVD 可讀回，實際浮點、裁切與 JPEG 仍需檢驗。

先單獨執行合成測試，通過才做影像。主要條件 Q10，Q20、Q30、無攻擊 PNG 作對照。主要門檻為同圖 |候選 PNG PSNR−原版 PNG PSNR|≤0.5 dB，另列 ≤1.0 dB 敏感度。兩個 PSNR 均以原圖為參照，JPEG PSNR 含嵌入與壓縮。以逐圖配對及合計 BER 檢視，保留全部結果，包括任何無攻擊失敗、退步或超出品質門檻。若只有部分影像符合門檻，只對該明示子集合解讀相近品質效果。
