# G5 前置｜原版 SVD 失效機制診斷

本次只觀察原版。以 [W0-D PR #14](https://github.com/Rookie-YCLin/matrix-jpeg-research/pull/14) 為執行基底，核對 main 正式規格 `b6f54f51fc439da17b06af579bbbb8ea924609d8` 與 [W0 #13](https://github.com/Rookie-YCLin/matrix-jpeg-research/pull/13)、[G2 #17](https://github.com/Rookie-YCLin/matrix-jpeg-research/pull/17)、[G3 #18](https://github.com/Rookie-YCLin/matrix-jpeg-research/pull/18)、[G4 #20](https://github.com/Rookie-YCLin/matrix-jpeg-research/pull/20) 的固定實驗。JPEG 僅讀取封存檔案。未執行新候選 BER。

## A｜實測排序

攔截上游實際嵌入 SVD 的回傳向量，在原版更新前複製 s，在原版區塊函式回傳後複製原地更新的 s′。另對逆 DCT 後的區塊重新進行同一 DCT、洗牌與 SVD，量測真正回到數值降序後的奇異值。完整原版嵌入在記憶體轉成 PNG 後，三張解碼像素皆與封存檔完全相同。立即重分解的最大絕對差為 0.0003663，以各塊最大奇異值正規化後最大 3.48×10⁻⁷。首輪對小奇異值使用固定絕對容差 2×10⁻⁵，未涵蓋 float32 逆轉換的尺度誤差。改以區塊最大奇異值（下限 1）縮放，驗證界為 16 倍 float32 機器 epsilon，保留實測差與像素等同性要求。

| 影像 | 區塊×通道 | s′₁>s′₀ | s′₁<s₂ |
|---|---:|---:|---:|
| astronaut | 12,288 | 47 | 609 |
| chelsea | 6,216 | 2 | 389 |
| coffee | 11,250 | 8 | 1,029 |
| 合計 | 29,754 | 57（0.19%） | 2,027（6.81%） |

令 Δⱼ=s′ⱼ−sⱼ。第一種換序恰發生於 Δ₁−Δ₀>s₀−s₁，第二種發生於 −Δ₁>s₁−s₂。實測第一種各有事件的影像與通道中，原始間距均值約 5.66–9.02，Δ₀ 均值皆為負，Δ₁ 皆為正。第二種原始下方間距均值約 4.40–6.52，Δ₁ 均值約 −10.17 至 −6.56。立即重分解後，57 個第一類區塊的第一票有 32 票錯，2,027 個第二類區塊的第二票有 344 票錯。兩類皆未發生的 27,670 區塊在此階段兩票全對。封存 PNG 上同兩類對應錯票變成 35、351，三張圖的最終 payload 仍全對。重新分解的 PNG、JPEG 奇異值皆降序，這是 SVD 的輸出慣例，不能用來識別某一原始奇異方向是否仍排在相同索引。[逐區塊資料](../outputs/run-g5-diagnostics/blocks.csv.gz) · [逐圖逐通道計數](../outputs/run-g5-diagnostics/ordering.csv)

## C｜相位公式的條件式審核

未在專案文件、Git 歷史或 GitHub 議題找到 DeepSeek 原式。以下只審核常見的平移後向下取整形式，不能歸為 DeepSeek 的確切原案。

若 Q(s)=φ+d(⌊(s−φ)/d⌋+t)，其中 t=1/4+b/2，令 u=((s−φ) mod d)/d ∈[0,1)，則 Q(s)−s=d(t−u)。兩種位元的最壞絕對誤差合計為 3d/4（b=1、u=0 可取等，b=0 的負側只有上確界）。此界不是最近點量化的 d/2。當 d=20、φ=4、s=0，兩個位元分別產生 −11、−1。即使 φ=0 也可能換序。例如 b=0、(s₀,s₁,s₂)=(22,22,15)、(d₁,d₂)=(36,20)，得到 (9,25,15)。下方換序例為 (40,19,18) 映為 (45,5,18)。

若日後另獲授權，數學上可將每個位元的可行值定為 `{φ+d(k+t) : k∈Z, φ+d(k+t)≥0}`，以最小平方改動選擇兩個格點，另加 q₀≥q₁≥s₂ 的聯合約束及固定的平手規則。單一無排序約束的非負格點，若最小格點為 a∈[0,d)，全域誤差上界為 max(a,d/2)；加入排序約束後，需另證明誤差界。相位只由事前固定的密鑰與可重現的區塊、通道、索引決定。盲擷取使用 ((σⱼ−φⱼ) mod dⱼ)/dⱼ 與原閾值，無需正確 payload，DWT、DCT、K-means 可維持。此形式需要同步改動嵌入及擷取，超出 main 現行只改擷取判決的規格，須另行授權。這裡只寫數學條件，沒有實作。

**研究判定。** 目前不建議進入正式 G5。排序問題已實測，且固定相位下的票翻轉有明顯描述性差異，但沒有相位介入證據。若日後重審，先取得確切原式，再以合成邊界例驗證非負、排序、位元可解碼和位移界。若另獲圖像實驗授權，先固定相位規則、原版對照、Q10 主條件、無攻擊要求及逐圖 PNG PSNR 容差（可沿用 G2 的 ±1.0 dB 作研究操作門檻）。逐圖配對、完整報告超門檻結果，並採影像層級的比較。
