# G5 前置｜原版 SVD 失效機制診斷

本次只觀察原版。以 [W0-D PR #14](https://github.com/Rookie-YCLin/matrix-jpeg-research/pull/14) 為執行基底，核對 main 正式規格 `b6f54f51fc439da17b06af579bbbb8ea924609d8` 與 [W0 #13](https://github.com/Rookie-YCLin/matrix-jpeg-research/pull/13)、[G2 #17](https://github.com/Rookie-YCLin/matrix-jpeg-research/pull/17)、[G3 #18](https://github.com/Rookie-YCLin/matrix-jpeg-research/pull/18)、[G4 #20](https://github.com/Rookie-YCLin/matrix-jpeg-research/pull/20) 的固定實驗。JPEG 僅讀取封存檔案。未執行新候選 BER。

## A｜實測排序

攔截上游實際嵌入 SVD 的回傳向量，在原版更新前複製 s，在原版區塊函式回傳後複製原地更新的 s′。另對逆 DCT 後的區塊重新進行同一 DCT、洗牌與 SVD，量測真正回到數值降序後的奇異值。完整原版嵌入在記憶體轉成 PNG 後，三張解碼像素皆與封存檔完全相同。立即重分解的最大絕對差為 0.0003663，以各塊最大奇異值正規化後最大 3.48×10⁻⁷。首輪對小奇異值使用固定絕對容差 2×10⁻⁵，未涵蓋 float32 逆轉換的尺度誤差。改以區塊最大奇異值（下限 1）縮放，驗證界為 16 倍 float32 機器 epsilon，保留實測差與像素等同性要求。

| 影像 | 區塊×通道 | s′₁>s′₀ | s′₁<s₂ |
|---|---:|---:|---:|
| astronaut | 12,288 | 47 | 609 |
| chelsea | 6,216 | 2 | 389 |
| coffee | 11,250 | 8 | 1,029 |
| 合計 | 29,754 | 57（0.19%） | 2,027（6.81%） |

令 Δⱼ=s′ⱼ−sⱼ。第一種換序恰發生於 Δ₁−Δ₀>s₀−s₁，第二種發生於 −Δ₁>s₁−s₂。實測第一種各有事件的影像與通道中，原始間距均值約 5.66–9.02，Δ₀ 均值皆為負，Δ₁ 皆為正。第二種原始下方間距均值約 4.40–6.52，Δ₁ 均值約 −10.17 至 −6.56。立即重分解後，57 個第一類區塊的第一票有 32 票錯，2,027 個第二類區塊的第二票有 344 票錯。兩類皆未發生的 27,670 區塊在此階段兩票全對。封存 PNG 上同兩類對應錯票變成 35、351，三張圖的最終 payload 仍全對。重新分解的 PNG、JPEG 奇異值皆降序，這是 SVD 的輸出慣例，不能用來識別某一原始奇異方向是否仍排在相同索引。[逐區塊資料](../outputs/run-g5-diagnostics/blocks.csv.gz) · [逐圖逐通道計數](../outputs/run-g5-diagnostics/ordering.csv)

## C｜DeepSeek 原式的數學審核

來源為研究主持人提供的 DeepSeek 顧問原文。原式對兩個奇異值共用 φ∈[0,20)，步長為 (36,20)。文字規格要求相位取決於密鑰、區塊和色彩通道，但偽程式只產生長度為區塊數的陣列，並以區塊索引取值，因此各通道共用相位。另外，原版擷取區塊呼叫只接收區塊和洗牌向量。若未來另獲授權，嵌入與擷取須明確傳入相同的區塊／通道索引，避免以可變的呼叫計數推定相位。

原式 Q(s)=φ+d(⌊(s−φ)/d⌋+t)，其中 t=1/4+b/2。固定 φ=0 時，輸出從 td 開始以 d 為間距向上。固定 0<φ<d 時，最小輸出為 φ−(1−t)d，向上同樣以 d 為間距，無上界。故 φ 位於 (0,(1−t)d) 時可產生負值。令 u=((s−φ) mod d)/d∈[0,1)，則 Q(s)−s=d(t−u)。位元 0 的有號誤差屬於 (−3d/4,d/4]，位元 1 屬於 (−d/4,3d/4]。兩種位元的全域最大絕對誤差為 3d/4，位元 1 在 s=φ 時取等。位元 0 的最大絕對誤差只有上確界。原版 φ=0 同樣適用此誤差推導。

主持人提供的例子 d=20、φ=1、s=0、b=0 確實得到 −14。對正交 U、V 重建的 U diag(q) Vᵀ，真正的奇異值為各 |qⱼ| 的降序排列。即使假定索引未變，擷取端看到 14 時，((14−1) mod 20)/20=0.65，會判為 1。若索引也變，擷取端還可能對移入該索引的值套用另一個步長。共用相位也無法保序。b=0、φ=1、(s₀,s₁,s₂)=(22,22,15) 映成 (10,26,15)，而 (40,19,18) 映成 (46,6,18)。

「PSNR 期望不變」缺乏推導。φ 只在 [0,20) 均勻，對 d=36 不覆蓋完整週期。即使 u 為全週期均勻，單一係數的期望平方改動也只是 7d²/48，並未建立它與原版失真的等式。影像級結果還取決於色彩變換、裁切、儲存量化及 PSNR 的對數。由 B 的封存資料可知，原版存在票翻轉的相位條件關聯，但原式會消除 JPEG 同向偏壓仍屬未驗證假說。

若日後另獲授權，數學上可將每個位元的可行值定為 `{φ+d(k+t) : k∈Z, φ+d(k+t)≥0}`，以最小平方改動選擇兩個格點，另加 q₀≥q₁≥s₂ 的聯合約束及固定的平手規則。單一無排序約束的非負格點，若最小格點為 a∈[0,d)，全域誤差上界為 max(a,d/2)。加入排序約束後須另證明誤差界。相位只由事前固定的密鑰與可重現的區塊和通道決定，同一區塊內兩項共用。盲擷取用 ((σⱼ−φ) mod dⱼ)/dⱼ 與原閾值。因可行值非負且保序，理想重建矩陣的同索引奇異值會落在正確的模數同餘類。PNG／JPEG 邊界仍須驗證。DWT、DCT、JPEG 和 K-means 可維持，此形式需要同步改動嵌入及擷取，超出 main 現行只改擷取判決的規格，須另行授權。這裡只寫數學條件，沒有實作。

**研究判定。** 目前不建議進入正式 G5。排序問題已實測，且固定相位下的票翻轉有明顯描述性差異，但沒有相位介入證據。修正版值得先做合成邊界驗證，檢查非負、排序、位元可解碼和位移界。若另獲圖像實驗授權，先固定相位規則、原版對照、Q10 主條件、無攻擊要求及逐圖 PNG PSNR 容差（可沿用 G2 的 ±1.0 dB 作研究操作門檻）。可另設零相位但相同保序約束的對照以區分兩種影響。逐圖配對、完整報告超門檻結果，並採影像層級的比較。

```text
python -m watermark_baseline.mechanism --output-dir outputs/g5-diagnostics-review
python -m watermark_baseline.mechanism --output-dir outputs/g5-diagnostics-review-repeat
python -m watermark_baseline.compare_runs outputs/g5-diagnostics-review outputs/g5-diagnostics-review-repeat
python -m pytest -v
```
