# 期末答辯稿｜JPEG 壓縮對影像奇異值與低秩結構之影響分析

## 開場與研究主線

「我把一張灰階影像當成矩陣。SVD 把它拆成多個外積矩陣，每個外積有一個奇異值當權重。我先用前幾項做重建，驗證捨棄項的奇異值平方和就是重建誤差平方。接著讓同一張原圖各自經過四種 JPEG 品質設定，比較解碼結果。」

「我問三件事。解碼圖離原圖多遠？解碼圖本身容易用低秩矩陣表示嗎？如果固定原圖的秩一方向，解碼後沿各方向的係數改變多少？這三個問題分別用 PSNR、自身相對平方誤差和有號投影回答。」

## 可能提問

| 提問 | 精簡回答 |
| --- | --- |
| 為何前 k 項是最佳近似？ | 秩至多 k 的候選只用最多 k 維的欄空間。投影到任何這樣的空間最多取得前 k 個奇異值的平方和。截斷 SVD 達到上限，所以 Frobenius 殘差最小。 |
| 為何 Q=40 的自身 Rank-100 誤差反而較低？ | 這張解碼圖的前 100 項占它自身平方能量的比例較高。較粗的量化可能減弱一些細節，使它更易近似，但它相對原圖的 PSNR 較低。 |
| 為何 PSNR 與自身低秩誤差不能直接比較？ | PSNR 以原圖為參照，衡量 JPEG 後的像素偏差。自身誤差比較解碼圖與它自己的截斷重建，再除以自身總平方能量。 |
| 投影係數與奇異值有何不同？ | 投影沿原圖固定方向，可能為負。解碼圖奇異值由解碼圖自行分解，皆非負。原圖有重複奇異值時，個別係數也會隨選用的基底而變。 |
| 為何可用尾端平方和檢查重建？ | 秩一方向在 Frobenius 內積下彼此正交且長度為一，故殘差平方等於各尾端權重平方相加。 |
| JPEG 與 Rank-k PNG 都是同一種壓縮嗎？ | JPEG 在局部區塊做 DCT 與量化。Rank-k PNG 只是把全影像 SVD 的截斷結果另存給人看。 |
| Q 可以當作壓縮率嗎？ | Q 是 Pillow 的編碼設定。儲存成本直接讀 JPEG 檔案位元組數，同一 Q 在不同影像上也可能得到不同大小。 |
| 能說 JPEG 對浮水印有多大影響嗎？ | 本研究測的是影像矩陣的變化。浮水印需要另定嵌入與提取方法，加入未壓縮對照，才能量測壓縮後的位元錯誤率。 |

收尾可用一句話說明限制。「這些趨勢只代表這張圖和這套編碼設定。低秩誤差小，表示容易近似自己。」
