# G6 教授角度的最終審查清單

本文件是 [G6 正式整合正文](G6_FINAL_PROJECT_REPORT.md) 的論證審查，並非新增實驗。

| 可能追問 | 必須回答的重點 |
|---|---|
| 你們自己做了什麼？ | 單參數 d1=36→90 的受控改良、固定主 QF15 的 BER 實驗、配對 PSNR，以及對現有 SVD-QIM 的矩陣理論分析。QIM、3:1 融合與 K-means 均為上游原有。 |
| 為什麼先改第一奇異值？ | 區塊分數是 (3h1+h2)/4，第一票權重較大。不能把 3/4 當成 BER 貢獻百分比。 |
| d/4 怎麼來？ | 量化格點模 d 後在 d/4、3d/4，最近判決邊界是 0 或 d/2。前提包括正確索引、理想格點。 |
| Bernstein 能證明 BER=0 嗎？ | 不能。Proposition 9.6.8 只能推奇異值擾動界；需知道同一變換域 E 且滿足條件，最終仍受區塊融合與 K-means 影響。 |
| 為何 PSNR 下降？ | 單塊 Frobenius 範數上界增加，提示可能代價；**數值 -1.671 dB 是實測**，不是理論上界直接推導。 |
| 為何 PNG 差 -6.600 dB、JPEG 差 -1.671 dB？ | 兩者是同一參照下各階段兩版本的差；不能直接扣出獨立 JPEG 失真，因為平方差有交叉項。 |
| 為什麼 QF15 全 32 bits 反向？ | 僅知原版輸出與真值逐位互補，真正機制未證明；不可猜測 K-means 標籤是唯一原因。 |
| 為什麼選 90 而不是別的？ | 有限 15 組候選中選定的單變因方案，非全域最佳參數。 |
| QF5 退步是否矛盾？ | 不矛盾，代表主條件 QF15 成功不能外推至所有低 QF；必須完整揭露。 |
| 可推廣到其他圖片嗎？ | 未驗證。額外 payload 仍用同一張圖；不聲稱泛化。 |
