# 粗搜＋細搜第二輪消融：分層隨機化與多區域探索

日期：2026-11-13。使用 PR #39 的單圖 150 個真實 JPEG 測得的 `model_b_lambda_0_5` Grid oracle；**本輪只是 Grid lookup replay，沒有執行新的 JPEG**。200 seeds（0–199）、固定 LCG 初始 state=seed+12345，12/24/48 個不重複整數 d1 查詢。原 Grid oracle d1=33，J=0.044210042965582494。

| 方法 | 12 次 mean J / hits | 24 次 mean J / hits | 48 次 mean J / hits |
|---|---|---|---|
| 固定粗搜＋單區細搜 | 0.118073 / 0 | 0.085905 / 52 | **0.044280 / 185** |
| 分層隨機粗搜＋單區細搜 | 0.090826 / 51 | 0.058569 / **128** | 0.053337 / 180 |
| 隨機粗搜＋單區細搜 | 0.089416 / 57 | 0.070497 / 114 | 0.054866 / 175 |
| 固定粗搜＋雙區交替細搜 | **0.074225** / 27 | **0.054245** / 66 | 0.044444 / **187** |
| 固定粗搜＋三區交替細搜 | 0.085825 / 11 | 0.065145 / 37 | 0.046307 / 153 |
| 固定粗搜＋20% 遠距探索 | 0.119167 / 0 | 0.089647 / 52 | 0.047710 / 160 |

hits 為 200 個 seeds 中命中全域最佳 objective 的次數。目標值愈低愈好。

## 診斷
- 分層隨機化改善 24 次預算下的命中率（52/200→128/200），但 48 次下平均目標值比固定粗搜差，並非全面勝出。
- 雙區交替在 24 次的**平均 J 最低**，但命中 oracle 次數少於分層隨機法。這兩個指標衡量不同風險，不能只挑一項宣稱勝利。
- 固定粗搜在 48 次有優勢，可能因為該單圖的最優區域與固定網格位置恰巧相配。
- 六種策略已在同一張圖上探索，接下來應把策略視為**開發集調參**，不得用這張圖聲稱泛化。

## 下一步
1. 對雙區交替與分層隨機策略做預先指定的混合設計（例如 50% 分層初始 + 雙區細搜），先做 12/24/48 次 budget 的同種子對照，不要在這張圖上無限制挑參數。
2. 加入每次查詢 trace、paired seeds、bootstrap CI，與修正過的 DE 及 BO 直接比較。
3. **正式驗證需新的獨立影像**，尤其低 QF 5–10。若新圖的最優區域移動，應測試搜尋策略能否適應。
4. 最終研究目標仍是嵌入前自動決定 d1；反覆攻擊的離線搜尋與零反覆測試的影像特徵預測必須分開評估。
