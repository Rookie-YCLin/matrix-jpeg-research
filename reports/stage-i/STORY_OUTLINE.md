# 階段 I｜研究故事大綱

**JPEG 壓縮對影像奇異值與低秩結構之影響分析**

先讓讀者看原圖、Q=40 和 Q=95 的同位置裁切，再把問題從局部外觀轉到全圖量測。接著用原圖截斷和小外積建立成分直覺，最後回到兩種比較基準。見[三頁樣稿](SAMPLE.pdf)。

| 章節 | 讀者的問題 | 核心主張與證據 |
| --- | --- | --- |
| 開場 | 為什麼 Q=40 比 Q=95 更不像原圖，卻較容易用 Rank-100 近似？ | 兩個量測比較的影像不同。用同一 Q 軸的上下圖讓讀者先看見排序差異。 |
| 看見低秩 | 為什麼保留一項畫不出斜欄杆？ | 原圖與 Rank 1、10、50、100 的共同裁切只比較截斷。用兩列等比例的小外積說明亮點不能靠縮放移位，再引入多項疊加。 |
| 解釋誤差 | 怎麼知道剩下的誤差有多大，還能不能做得更好？ | 由正交的秩一項推得尾端平方和，配合影像例子讀出自身誤差。正文說明最佳性的意義，欄空間投影的完整證明置於附錄。 |
| 回到 JPEG | 我們如何分辨編碼的效果與分析工具的效果？ | 中文流程示意先交代同一原圖獨立編碼，再說明局部 DCT／量化與整圖 SVD 分工。檔案大小圖只回答儲存代價，不重述主圖。 |
| 固定方向 | 頻譜可以告訴我原本的哪一個成分改變了嗎？ | 各圖的 SVD 會各選方向。以原圖的秩一方向固定參照，緊接公式及有號投影例子。 |
| 收束 | 這組結果能支持到哪裡？ | 回到 Q=40 的反直覺觀察，說明能量集中與原圖失真可以同時發生，結論限於單張灰階圖及指定編碼設定。 |
